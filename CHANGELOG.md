## [2.0.0] - 2025-11-21

### 🎯 ВАЖНЫЕ ИЗМЕНЕНИЯ

#### Извлечение данных из имени файла

**ДО:**
- ФИО извлекалось из содержимого PDF (ненадёжно)
- Поиск пациента только по ФИО
- Автоматическое создание дубликатов при опечатках

**СЕЙЧАС:**
- ✅ **ФИО и дата рождения извлекаются из имени файла**
- ✅ Формат: `Фамилия Имя Отчество ДД.ММ.ГГГГ.pdf`
- ✅ Поиск по уникальной комбинации: ФИО + дата рождения
- ✅ **НЕ создаём пациентов автоматически** - только поиск
- ✅ Явная ошибка если пациент не найден

### ✨ Добавлено

- **Парсинг имени файла** (`app/pdf_parser.py`)
  - Функция `_parse_filename()` - извлечение ФИО и даты
  - Автоматический расчёт возраста из даты рождения
  - Обработка различных форматов имён файлов
  
- **Поиск пациента в 1С** (`docs/1c-integration-FIXED.md`)
  - Функция `НайтиПациента(ИмяПолное, ДатаРождения)`
  - Поиск по уникальной комбинации ФИО + дата
  - Конвертация даты из строки в формат 1С
  
- **Метод createAppointment** (`docs/1c-integration-FIXED.md`)
  - Автоматическое создание документа "Прием"
  - Заполнение HTML шаблона
  - Врач "МД Lab" и шаблон "МД Биохимический анализ крови"
  
- **Документация**
  - `FILE-NAMING-GUIDE.md` - подробное руководство по именованию файлов
  - Обновлён `README.md` - новый workflow
  - Обновлён `docs/1c-integration-FIXED.md` - код для 1С

### 🔧 Изменено

- **pdf_parser.py**
  - Метод `parse()` теперь использует `_parse_filename()`
  - Новые методы: `_parse_dates_from_pdf()`, `_parse_gender_from_pdf()`
  - Удалён старый метод `_parse_metadata()`
  - ФИО и дата рождения больше НЕ извлекаются из PDF
  
- **Формат JSON для 1С**
  - Добавлено поле `birth_date`
  - Возраст вычисляется автоматически
  - Результаты анализов в отдельном объекте `test_results`

### 🐛 Исправлено

- Дубликаты пациентов из-за опечаток в ФИО
- Ненадёжный парсинг ФИО из PDF
- Автоматическое создание лишних записей в 1С
- Отсутствие уникальной идентификации пациента

### 🚨 Breaking Changes

#### Требуется обновление названий файлов!

**Старый формат:**
```
123456.pdf
test_result.pdf
```

**Новый формат (обязательный):**
```
Иванов Иван Иванович 21.05.1982.pdf
Петрова Мария Сергеевна 15.03.1995.pdf
```

**Что делать:**
1. Переименовать существующие файлы в новый формат
2. Настроить лабораторию на новый формат экспорта
3. Использовать скрипты для массового переименования (см. `FILE-NAMING-GUIDE.md`)

## [1.0.0] - 2025-11-20

### ✨ Первый стабильный релиз

#### Добавлено

- **Backend**
  - FastAPI приложение (`app/main.py`)
  - Watcher для мониторинга NAS (`app/watcher.py`)
  - Integrator для отправки в 1С (`app/integrator.py`)
  - Mailer для email (`app/mailer.py`)
  - JWT аутентификация (`app/auth.py`)
  - SQLite база данных (`app/database.py`)
  - Парсер PDF (`app/pdf_parser.py`)
  
- **Frontend**
  - Веб-интерфейс на Tailwind CSS + HTMX
  - Панель управления с статистикой
  - Журнал аудита
  - Повторная обработка файлов
  
- **Инфраструктура**
  - Docker + Docker Compose
  - Nginx с SSL (Let's Encrypt)
  - OpenVPN интеграция
  - Systemd сервис
  
- **Документация**
  - `README.md` - описание проекта
  - `docs/deployment-guide.md` - развертывание
  - `docs/openvpn-setup-guide.md` - настройка VPN
  - `docs/1c-integration.md` - код для 1С
  
- **Безопасность**
  - HTTPS с SSL
  - JWT токены
  - Bcrypt для паролей
  - Firewall (UFW)
  - Шифрованный OpenVPN туннель
  
- **Мониторинг**
  - Health check endpoint
  - Логирование всех операций
  - Аудит в БД
  - Скрипт проверки системы (`check-system.sh`)
